# 实体规格字段表

## 网球视频 Video

### 核心业务字段

| 字段 | 业务含义 | Django 字段类型 | 数据来源 | 必填性 | 默认值 | 验证规则 |
|---|---|---|---|---|---|---|
| `id` | 视频记录的唯一标识 | Django 自动生成的主键 | 系统生成 | 是 | 自动生成 | 必须唯一 |
| `file` | 用户上传的视频文件 | `FileField` | 用户上传 | 是 | 无 | 文件不能为空；允许的格式和大小上限待确定 |
| `player_count` | 画面中实际参与击球的人数 | `PositiveSmallIntegerField` | 用户填写 | 是 | 无 | 最小值为 1；最大值待确定 |
| `camera_shaking` | 相机是否发生晃动 | `BooleanField` | 用户选择 | 是 | 无 | 必须明确选择“是”或“否” |
| `viewpoint` | 视频的拍摄视角 | `CharField` + `TextChoices` | 用户选择 | 是 | 无 | 只能选择地板视角、支架视角或高位摄像机视角 |
| `created_at` | 视频上传时间 | `DateTimeField` | 系统生成 | 是 | 自动记录 | 创建视频记录时自动生成，不允许用户修改 |

### 实体关系字段

| 字段 | 业务含义 | Django 字段类型 | 数据来源 | 必填性 | 默认值 | 验证规则 |
|---|---|---|---|---|---|---|
| `uploaded_by` | 上传该视频的用户 | `ForeignKey(settings.AUTH_USER_MODEL, on_delete=PROTECT, related_name="uploaded_videos")` | 系统从当前登录用户获取 | 是 | 无 | 创建视频时用户必须已登录；用户存在已上传视频时，不允许物理删除用户 |
| `tags` | 视频拥有的标签 | `ManyToManyField(Tag, blank=True, related_name="videos")` | 用户选择 | 否 | 无，初始没有标签关联 | 视频可以不选择标签，也可以选择多个标签；所选标签必须已经存在 |

### 文件技术元数据

| 字段 | 业务含义 | Django 字段类型 | 数据来源 | 必填性 | 默认值 | 验证规则 |
|---|---|---|---|---|---|---|
| `file_size_bytes` | 视频文件大小，单位为字节 | `PositiveBigIntegerField` | 系统读取 | 是 | 无 | 必须大于 0；不得超过上传大小限制 |
| `duration` | 视频时长 | `DurationField` | 系统提取 | 提取前可为空，成功后应有值 | 无 | 必须大于 0 |
| `container_format` | 视频容器格式 | `CharField` | 系统提取 | 提取前可为空，成功后应有值 | 无 | 只能是允许的格式，例如 `mp4`、`mov`、`webm` |
| `width_pixels` | 视频画面宽度，单位为像素 | `PositiveIntegerField` | 系统提取 | 提取前可为空，成功后应有值 | 无 | 必须大于 0 |
| `height_pixels` | 视频画面高度，单位为像素 | `PositiveIntegerField` | 系统提取 | 提取前可为空，成功后应有值 | 无 | 必须大于 0 |
| `frame_rate` | 视频帧率，单位为 FPS | `DecimalField` | 系统提取 | 提取前可为空，成功后应有值 | 无 | 必须大于 0，例如 `29.970`、`30.000`、`60.000` |
| `video_codec` | 视频流使用的编码格式 | `CharField` | 系统提取 | 提取前可为空，成功后应有值 | 无 | 记录规范化编码名称，例如 `h264`、`hevc`、`vp9`、`av1` |

这样 `Video` 的字段被分为三组：

1. 核心业务字段：描述视频本身和用户填写的信息。
2. 实体关系字段：实现用户—视频、视频—标签之间的关系。
3. 文件技术元数据：系统从视频文件中读取或提取的信息。

## 标签 Tag

| 字段 | 业务含义 | Django 字段类型 | 必填 | 默认值 | 验证规则 |
|---|---|---|---|---|---|
| `id` | 标签记录的唯一标识 | Django 自动生成的主键 | 是 | 自动生成 | 必须唯一 |
| `name` | 标签名称 | `CharField` | 是 | 无 | 不能为空；名称不能重复；最大长度待确定 |

“拉球、比赛、多球练习”是标签表中的三条**初始数据**，不是 `name` 字段的默认值。

## 用户 User

当前上传功能不需要重新设计用户的用户名、密码等字段，可以明确写：

> 用户实体复用 Django 自带的用户模型，通过 `settings.AUTH_USER_MODEL` 引用，本次不创建新的 User 模型。
